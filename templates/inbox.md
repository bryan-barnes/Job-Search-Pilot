# Job inbox

Paste links to postings you spot, one per line, with a note if you like. The board's "Add job"
button is the quickest way to add one yourself; this file is for links you want an AI agent
working in this folder (Claude Code, OpenCode) to verify and add for you.

Any agent working in this folder: verify each one, add it to jobs.js following AGENTS.md, then
delete the line here.
